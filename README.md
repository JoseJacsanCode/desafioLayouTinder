# 🔥 Layout Tinder

Réplica do layout do Tinder feita em **Flutter**, desenvolvida como resposta ao desafio proposto por **Jacob Moura**, da comunidade [Flutterando](https://flutterando.com.br/).

O objetivo é praticar a construção de interfaces em Flutter, reproduzindo fielmente a tela principal do app: cartão de perfil, botões de ação e barra de navegação.

## ✨ O que foi praticado

- Composição de layouts com `Column`
- Uso de imagenm local (`assets`)
- Estilização de textos e do botão elevatedButton
- Organização do código em `lib/`

## 🚀 Como executar

### Pré-requisitos

- [Flutter SDK](https://docs.flutter.dev/get-started/install) instalado
- Um emulador, dispositivo físico ou navegador configurado

Confira se o ambiente está certo:

```bash
flutter doctor
```

### Passo a passo

```bash
# 1. Clone o repositório
git clone https://github.com/JoseJacsanCode/desafioLayouTinder.git

# 2. Entre na pasta
cd desafioLayouTinder

# 3. Instale as dependências
flutter pub get

# 4. Execute o app
flutter run
```

## 🎯 Sobre o desafio

Desafio proposto por Jacob Moura (Flutterando) para treinar a criação de layouts em Flutter a partir de uma referência visual, sem foco em regras de negócio ou backend.
